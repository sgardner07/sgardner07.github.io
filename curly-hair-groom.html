Curly Hair Groom

A groom of a curly hairstyle

Project Breakdown

This groom was my first time using Houdini's grooming tools, and I ambitiously chose a curly-haired reference image, thinking that it couldn't be too difficult to art-direct and manage curls. I quickly learned that it was a lot more difficult than I thought! With a lot of trial, error, and research, I found a great solution for creating curls involving quaternions and matrices. This project helped me realize how I can combine math and code with pre-existing tools to get the look that I want.
